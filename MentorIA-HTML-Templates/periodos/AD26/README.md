# Periodo AD26

Plantillas de comunicación utilizadas durante el semestre Agosto–Diciembre 2026.

## Organización sugerida

- `semana-contigo/`: comunicaciones semanales de seguimiento general para población de mentoría.
- `momentos/`: campañas o hitos transversales del semestre (inicio, mitad, cierre, inscripciones, etc.).
- `segmentos/`: usar la carpeta global `../../segmentos/` cuando la plantilla sea reutilizable por perfil académico (primer semestre, transferencias, último semestre, etc.).

## Convención de nombres

`semana-XX-tema-breve.html`

Ejemplo:
`semana-07-checkin-mitad-semestre.html`

Los recursos visuales específicos del periodo se almacenan en:
`../../assets/AD26/`

Mantener HTML basado en tablas y estilos en línea para compatibilidad con Outlook y Power Automate.
